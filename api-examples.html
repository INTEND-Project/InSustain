POST /application

Register an application for energy monitoring. Use k8s_labels for dynamic discovery or microservices for static pod list.

Example 1: Using k8s_labels (Dynamic Discovery)

curl -X POST "http://localhost:8089/application" \
  -H "Content-Type: application/json" \
  -d '{
    "id": "0",
    "name": "Backend API",
    "k8s_labels": {
      "app.kubernetes.io/name": "backend"
    },
    "namespace": "insustain"
  }'

Example 2: Using microservices (Static Pod List)

curl -X POST "http://localhost:8089/application" \
  -H "Content-Type: application/json" \
  -d '{
    "id": "1",
    "name": "App Simulator",
    "microservices": [
      {"pod_name": "app-simulator-7d8f9c5b6-x4k2p", "node_name": "worker-1"},
      {"pod_name": "app-simulator-7d8f9c5b6-m9n7q", "node_name": "worker-2"}
    ]
  }'

Response (201 Created)

{
  "internal_id": "a1b2c3d4-e5f6-4789-a012-3456789abcde",
  "id": "0",
  "name": "Backend API",
  "k8s_labels": {
    "app.kubernetes.io/name": "backend"
  },
  "status": "unknown",
  "last_check": "2025-02-09T10:30:00Z",
  "monitoring_method": "k8s_labels"
}

GET /analytics

Retrieve energy consumption metrics for a registered application.

Query Parameters

Parameter Type Description Example
event-id string Metric type: CPU_JOULES, DRAM_JOULES, BPF_CPU_TIME_US CPU_JOULES
app_id string Application identifier 0
ana-req JSON string Time range: {"offsetPeriod": -60} for last 60 seconds {"offsetPeriod": -60}

Example Request

curl -X GET "http://localhost:8089/analytics?event-id=CPU_JOULES&app_id=0&ana-req=%7B%22offsetPeriod%22%3A-60%7D"

Response (200 OK)

{
  "analytics_subset": [
    {
      "timestamp": "2025-02-09T10:29:00Z",
      "metric_value": 0.8008281904610115,
      "metric_name": "kepler_container_joules_total",

    {
      "timestamp": "2025-02-09T10:29:30Z",
      "metric_value": 0.8523456789012345,
      "metric_name": "kepler_container_joules_total",
      "aggregation_level": "backend-pod-1",
      "resource_id": "container-abc123"

}

GET /predict

Get ML model prediction for energy consumption based on application parameters.

Example Request

curl -X GET "http://localhost:8089/predict?app-params=%7B%22locust_users%22%3A40%7D&event-id=CPU_JOULES&app_id=0"

Response (200 OK)

{
  "analytics_subset": [
    {
      "metric_value": 1.2345678901234567,
      "metric_name": "kepler_container_joules_total",
      "app_params": "locust_users"
    }
  ]
}

WS /ws

WebSocket endpoint for real-time streaming of energy metrics.

JavaScript Example

const ws = new WebSocket('ws://localhost:8089/ws');

ws.onopen = () => {
  // Send analytics request
  ws.send(JSON.stringify({
    payload: {
      query: {
        event_id: 'CPU_JOULES',
        analyticsSubsets: '"appIds":["0"]',
        offset: -60
      },
      id: 'request-1'
    }
  }));
};

ws.onmessage = (event) => {
  const data = JSON.parse(event.data);
  console.log('Received:', data);
};

Common Error Responses

404 Not Found

{
  "error": "not_found",
  "message": "Application with id '0' not found",
  "guidance": "Verify the application ID is correct and the application has been registered"
}

403 Forbidden (Insufficient Permissions)

{
  "error": "permission_denied",
  "message": "Kubernetes API access not available. Cannot use k8s_labels method without RBAC permissions.",
  "guidance": "Re-register this application using the 'microservices' field with static pod names",
  "available_methods": ["microservices"]
}

503 Service Unavailable

{
  "error": "external_service_error",
  "message": "Unable to retrieve metrics from Prometheus for any of the 2 pods",
  "guidance": "Check that Prometheus and Kepler are running. Verify pods are exposing metrics.",
  "failed_pods": ["backend-pod-1", "backend-pod-2"]
}

Quick Start Guide

1. Check API Health

curl http://localhost:8089/health

2. Register Your Application

curl -X POST http://localhost:8089/application \
  -H "Content-Type: application/json" \
  -d '{"id":"0","name":"My App","k8s_labels":{"app":"myapp"}}'

3. Get Energy Metrics

curl "http://localhost:8089/analytics?event-id=CPU_JOULES&app_id=0&ana-req=%7B%22offsetPeriod%22%3A-60%7D"

Available Metric Types

  • CPU_JOULES - CPU energy consumption in joules
  • DRAM_JOULES - DRAM energy consumption in joules
  • BPF_CPU_TIME_US - BPF CPU time in microseconds

1. Access the Locust GUI via SSH tunnel:
   - Forward the port from your local machine to the cluster:
     ssh -L 8099:localhost:8099 <user>@<cluster-node>
   - Or, if already inside a jump host, use kubectl port-forward:
     kubectl port-forward -n locust <locust-pod-name> 8099:8099
   - Open your browser at: http://localhost:8099

2. Locust simulation:
   - User class: HLSUser
   - Task: view_stream()
     * Fetches HLS playlist from SRS host
     * Downloads last 3 video segments
     * Waits 0.5s between segment downloads
   - Wait time between tasks: 0.2 - 0.6 seconds

3. Performance notes:
   - RPS depends on number of users, task duration, and wait_time
   - If RPS seems low, check CPU/network limits or task pacing

4. Monitoring & Metrics:
   - Exporter: containersol/locust_exporter is deployed as a sidecar
   - Metrics endpoint: :9646/metrics (inside cluster)
   - ServiceMonitor enabled for Prometheus in "monitoring" namespace
   - Interval: 5 seconds
